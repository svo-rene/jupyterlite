Dateien vom eigenen Rechner öffnen

Normalerweise liegen die Dateien im Speicher des Browsers. Es geht aber auch direkt mit einem Ordner auf deiner Festplatte: In JupyterLab findest du links in der Leiste einen zweiten Dateibrowser namens Local File System. Dort wählst du einen Ordner aus, der Browser fragt einmal nach Erlaubnis – danach öffnest und speicherst du Notebooks direkt in diesem Ordner, ganz ohne Hoch- und Herunterladen.

Prüfe deinen Browser …

Dahinter steckt die File System Access API, die es bisher nur in Chromium-Browsern gibt: Chrome, Edge, Opera und Brave. In Firefox und Safari erscheint der zweite Dateibrowser gar nicht erst – dort gehen Dateien nur über die Schaltflächen zum Hochladen und über Datei → Download.

Notebooks in Forgejo speichern

Wer ein Konto auf git.inf7.eu hat, meldet sich in JupyterLab über die Wolke in der linken Leiste an. Dort holst du ein Repository als Ordner in die Dateiliste und arbeitest darin wie gewohnt. Hochladen speichert deine Änderungen als Commit im Repository, Aktualisieren holt, was sich dort inzwischen geändert hat. So sind deine Notebooks auf jedem Rechner wieder da.

Geändert wird nur, was du selbst angestoßen hast: Ohne Hochladen bleibt alles im Browser. Hast du eine Datei geändert, die auch im Repository geändert wurde, bleibt deine Version stehen und die aus Forgejo landet daneben, zum Vergleichen.

Ein Notebook per Link weitergeben

Hängst du ?fromURL= und die Adresse einer .ipynb-Datei an, wird diese beim Öffnen heruntergeladen und angezeigt. So teilst du ein Notebook, ohne dass jemand etwas installieren oder hochladen muss.

Adresse eintragen und auf „Link erzeugen“ klicken.

Die Adresse muss auf die Datei selbst zeigen und von fremden Seiten abrufbar sein: Bei GitHub also der raw.githubusercontent.com-Link (Schaltfläche Raw), nicht die normale GitHub-Seite. Mehrere fromURL hintereinander öffnen mehrere Dateien, etwa ein Notebook samt Datensatz. Mit &fromURLToFolder=uebungen landen sie in einem Ordner, der bei Bedarf angelegt wird.

Diese Seite läuft mit JupyterLite. Empfohlen wird ein Chromium-Browser (Chrome, Edge, Opera, Brave); in Firefox funktioniert alles außer dem Zugriff auf lokale Ordner.
